Connect to your repo

This page talks directly to GitHub's API from your browser - there's no server in between, and nothing is sent anywhere except api.github.com. You'll need a personal access token so it's allowed to read and update config.json (and optionally trigger a check).

How do I get a token?

1. Go to github.com/settings/personal-access-tokens/new (fine-grained tokens).
2. Under "Repository access," choose "Only select repositories" and pick this repo (Flight-Tracker).
3. Under "Permissions" → "Repository permissions," set Contents to "Read and write." If you want the "Run a check now" button to work too, also set Actions to "Read and write."
4. Generate the token and paste it below. It's saved only in this browser (localStorage) - never shared, never sent anywhere but GitHub. You can revoke it anytime from that same GitHub settings page.
